skrf.calibration.calibration.MRC#

class skrf.calibration.calibration.MRC(measured, ideals, *args, **kwargs)[source]#

Misalignment Resistance Calibration.

This is an error-box based calibration that is a combination of the SDDL[1]_ and the UnknownThru[2]_, algorithms. The self-calibration aspects of these two algorithms alleviate the need to know the phase of the delay shorts, as well as the exact response of the thru. Thus the calibration is resistant to waveguide flange misalignment.

References

[1]

Z. Liu and R. M. Weikle, “A reflectometer calibration method resistant to waveguide flange misalignment,” Microwave Theory and Techniques, IEEE Transactions on, vol. 54, no. 6, pp. 2447-2452, Jun. 2006.

[2]

A. Ferrero and U. Pisani, “Two-port network analyzer calibration using an unknown thru,” IEEE Microwave and Guided Wave Letters, vol. 2, no. 12, pp. 505-507, 1992.
